Acerca de este Proyecto

He creado este proyecto con el propósito de aprender a construir una aplicación web real de principio a fin.

Para ello, he diseñado y desarrollado esta plataforma de gestión y consulta de técnicas de artes marciales.

El acceso es exclusivo para miembros de SBW

📖 ¿Cómo utilizar la plataforma?

1

Crea tu Cuenta

Regístrate para poder acceder. Recuerda revisar tu bandeja de entrada para validar tu correo electrónico antes de acceder por primera vez. Se trata de una web privada, un administrador te tendrá que dar acceso una vez te hayas registrado.

2

Explora y Filtra

Usa el buscador principal para localizar técnicas por su nombre. Puedes activar los filtros avanzados para aislar disciplinas o etiquetas específicas.

3

Visualiza el Detalle

Haz clic sobre cualquier tarjeta para acceder a la ficha técnica. Allí encontrarás la descripción completa y un reproductor interactivo con sus vídeos demostrativos.

4

Adapta tu Interfaz

¿Entrenando de noche o de día? Utiliza el interruptor del menú superior para alternar instantáneamente entre el Modo Claro y el Modo Oscuro.

💻 Información para Desarrolladores

Este sitio web ha sido construido bajo una arquitectura moderna, desacoplando la interfaz de usuario de la persistencia de datos mediante una API RESTful asíncrona.

🚀 Tecnologías Core

  • Backend: FastAPI (Python 3.10) de alta velocidad.
  • Base de Datos: Modelado relacional SQL mapeado mediante SQLAlchemy ORM.
  • Frontend: Estructura fluida con Jinja2 Templates, JavaScript Vanilla y Tailwind CSS.

🛡️ Mecanismos de Seguridad

  • Contraseñas encriptadas mediante algoritmos Hash robustos (bcrypt).
  • Sesiones blindadas con Tokens JWT firmados en Cookies HttpOnly.
  • Sistema de verificación de identidad por correo y panel de aprobación de roles.

🛡️ Transparencia y Privacidad de Datos

Al tratarse de una plataforma privada orientada al aprendizaje y al uso comunitario cerrado, la gestión de tus datos se rige bajo principios estrictos de transparencia y seguridad:

1. ¿Qué datos se recopilan?

Únicamente guardamos tu dirección de correo electrónico (para validar tu identidad) y tu contraseña. Tu contraseña se almacena de forma completamente cifrada mediante algoritmos criptográficos irreversibles (hash), lo que significa que nadie (ni siquiera el administrador) puede conocerla.

2. Uso de Cookies Técnicas

Esta web utiliza exclusivamente cookies técnicas de sesión con el único fin de mantenerte identificado. No se utilizan cookies de seguimiento, ni de analítica de comportamiento, ni de publicidad de terceros, cumpliendo con las excepciones de consentimiento de la normativa vigente.

3. Control de tus Datos

Tus datos jamás serán compartidos, vendidos ni transferidos a ninguna entidad externa. Si en cualquier momento deseas dar de baja tu cuenta y borrar de manera definitiva tu correo del servidor, solo tienes que pulsar el botón de "Eliminar Cuenta" en tu perfil.
